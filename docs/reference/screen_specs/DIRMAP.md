# docs/reference/screen_specs

Purpose: single-source directory for UI screen specification documents consumed by downstream scaffold and review stages.

## Contents
- `_template.md`: canonical screen spec template copied verbatim from `/Users/stuart/repos/gridl/mike_dev/guides/ui_screen_specs.md`.
- `_component_*.md`: shared component specification files (naming convention for reusable UI components).
- `<screen_name>.md`: screen-specific specification files created by copying `_template.md` first.

## Authoring rule
- Before creating a new spec, copy `docs/reference/screen_specs/_template.md` and then fill in screen-specific values; do not author ad-hoc structures.
